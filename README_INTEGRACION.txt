NASER - INTEGRACION CON EL PROYECTO EXISTENTE

1. Copia el contenido de esta carpeta dentro del repositorio que compartis con tus compañeros.
2. Si tu proyecto ya tiene index.html, style.css o img/, NO los reemplaces sin revisar. Este paquete usa el index y CSS corporativo que veníamos trabajando.
3. La parte nueva del sistema está dentro de php/.
4. En XAMPP, coloca el repositorio dentro de C:\xampp\htdocs\NOMBRE_PROYECTO
5. Inicia Apache y MySQL.
6. En phpMyAdmin importa php/database.sql.
7. Abre: http://localhost/NOMBRE_PROYECTO/php/
8. Usuario inicial: admin@naser.com
   Contraseña: admin123
9. Para conectar la web principal con el login agrega un enlace hacia php/login.php.
10. Para compartirlo: git add . ; git commit -m "agrego sistema php y base de datos" ; git push

IMPORTANTE: cada compañero debe importar php/database.sql en su propia instalación local de MySQL.
